# Muse 小红书工具包

给 Muse（云端 Ubuntu）用的小红书全流程工作台。**默认全离线、不碰账号。**

9 个 skill，覆盖：违规检测 → 标题优化 → 选题 → 写稿 → 配图 → 多平台改写 → 复盘 → 知识沉淀 → 每日简报。

---

## 快速安装

```bash
git clone https://github.com/vast777b-svg/muse-xhs-kit.git
cd muse-xhs-kit
bash install.sh
```

装完先做一件事：填 `~/xhs/persona.md`。人设决定所有文案的语气，**空着的话其他分析参考价值有限**。

## 九个 skill

### 核心三件套（你最初要的）

| Skill | 能力 |
|---|---|
| `xhs-compliance-check` | **违规词检测**。8 类词库 + 手机号/外链识别，风险分三级，给替换建议。纯本地 |
| `xhs-title-optimizer` | **标题优化**。诊断病灶 → 5 种骨架 → 20 字压缩法 |
| `xhs-viral-remix` | **爆款拆解与仿写**。5 层拆解模型 + 换骨不换皮 + 洗稿红线判定 |

### 知识沉淀层

| Skill | 能力 |
|---|---|
| `xhs-knowledge-base` | **本地知识库**。persona 人设、patterns 爆款库、topics 选题池、reviews 复盘，全存 Markdown |
| `xhs-topic-ideas` | **选题生成**。从人设+爆款库推选题，五维评分（相关性/独特性/可验证/互动/风险） |
| `xhs-account-audit` | **账号体检**。粘数据算指标，翻译成行动建议，识别"数据断层"关键期 |

### 生产与分发层

| Skill | 能力 |
|---|---|
| `xhs-card-render` | **3:4 图文卡片**。HTML+Playwright 本地渲染，三套主题，文字绝不糊 |
| `xhs-multi-platform` | **多平台改写**。小红书 → 公众号/抖音口播/微博/知乎，换开头换结构换密度 |
| `xhs-daily-digest` | **每日简报 + 定时任务**。从知识库生成今日行动清单，可接 crontab |

### 可选：自动发布（`--with-publish`）

`xiaohongshu-mcp` Linux 二进制：登录、发布图文/视频、搜索、评论、点赞、收藏。

## 完整工作流

```
填 persona.md
      ↓
选题（xhs-topic-ideas）→ 存进 topics/
      ↓
写稿（参考 patterns/ 里的骨架）
      ↓
标题优化（xhs-title-optimizer）
      ↓
违规检测（xhs-compliance-check）  ← 高危清零才继续
      ↓
【人工通读】                      ← 必须！机器过不了这关
      ↓
渲染卡片（xhs-card-render）
      ↓
发布（可选，装了 --with-publish）
      ↓
【人工确认后点发布】              ← 必须！
      ↓
7 天后体检（xhs-account-audit）→ 存进 reviews/
      ↓
沉淀回 patterns/ 和 persona.md   ← 越用越准
```

## 手动步骤清单

### 基础包 — 只有一处需要你手动

| 步骤 | 为什么 |
|---|---|
| **填 `~/xhs/persona.md`** | 你的身份、受众、语气、真实细节，机器猜不出来 |

其余全自动。装完直接可用。

### 自动发布（`--with-publish`）— 额外 4 处人工闸门

| # | 步骤 | 为什么必须手动 |
|---|---|---|
| 1 | 运行 `./xiaohongshu-login`，**手机扫码** | 二维码是图片，Muse 碰不到你的手机 |
| 2 | 触发短信/人机验证时手动过 | 验证码只发到你手机 |
| 3 | 首次发布前**人工通读文案** | 机器判不出"像不像人话""会不会被误解" |
| 4 | 点击**发布**前确认 | 发出去收不回 |

隐性手动点两个：
- **首次登录大概率失败一次** —— Muse 机房 IP，小红书判异地。重试即可，超 3 次别硬试
- **首次运行下载 150MB 无头浏览器** —— 慢的话耐心等


## 安全边界

这台机器能碰到你真实的小红书账号，守住这几条：

| 红线 | 说明 |
|---|---|
| ❌ 不要关掉人工闸门 | 通读和确认发布是唯一保险 |
| ❌ 不要批量高频发布 | 一天超 3 篇是风控首要信号 |
| ❌ 不要在凌晨自动跑 | 行为模式异常会拉高风险分 |
| ❌ 不要把 cookie/登录态贴进对话 | 会被记录进会话历史 |
| ✅ 先用小号试 | 验证流程跑通再上主号 |

详细的 A/B/C 三层风险分级见 [RISK-LEVELS.md](RISK-LEVELS.md)。

**定时任务只做只读本地文件的事**（简报、提醒）。自动发布、自动回复、批量互动**故意不提供定时能力**，那是封号最快的路径。

## 依赖

| 组件 | 需要 | 说明 |
|---|---|---|
| 大部分 skill | Python 3.7+ | 无第三方依赖，标准库足够 |
| `xhs-card-render` | playwright + chromium | `pip install playwright && playwright install chromium` |
| `--with-publish` | Linux x86_64 | 官方不支持 ARM64，脚本会自动检测 |

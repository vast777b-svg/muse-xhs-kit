# 多平台改写分发

同一个内容，**换平台不是换容器，是换讲法**。

## 平台差异对照

| 平台 | 标题 | 正文 | 语气 | 核心指标 |
|---|---|---|---|---|
| **小红书** | ≤20 字，情绪钩子 | ~1000 字，短段，emoji | 朋友聊天 | 收藏、点赞 |
| **公众号** | ≤64 字，可长可短 | 1500-3000 字，有小标题 | 作者视角，可深度 | 完读率、在看 |
| **抖音/视频号** | 15 字内抓住 | 300-600 字口播（1.5-3 分钟） | 说话感，短句 | 前 3 秒留存 |
| **微博** | ≤30 字 | ≤140 字（长微博另算） | 观点直给 | 转发 |
| **知乎** | 问题式 | 逻辑链完整，有论据 | 理性、有边界 | 赞同、收藏 |

## 改写的三个动作

### 动作一：换开头

小红书靠**情绪钩子**开头，公众号靠**场景或问题**，抖音靠**结论或冲突**，知乎靠**定义问题**。

同一个素材：

- 小红书：「被 AI 惊到了」
- 公众号：「用了三个月 AI，我改掉了三个工作习惯」
- 抖音口播：「先说结论，AI 帮我省下的不是时间，是注意力。」
- 知乎：「如何评价 AI 对日常工作效率的实际影响？」

### 动作二：换结构

| 平台 | 结构偏好 |
|---|---|
| 小红书 | 结论前置，分点短，一段一个意思 |
| 公众号 | 可以有铺垫，用故事引入，小标题分段 |
| 抖音 | 每 15 秒一个信息点，必须一直有钩子 |
| 知乎 | 先界定概念，再论证，最后给边界 |

### 动作三：换密度

小红书**密度最高**（每句话都在给信息或情绪）。
公众号**可以稀释**（有空间展开背景和论证）。
抖音**必须最浓缩**（口播稿念出来超过 3 分钟就废了）。

## 产出格式

```
【原文摘要】
<一句话说清这篇讲什么>

【改写方案】

### 公众号版
标题：<64 字内>
结构：<几个小标题>
字数预估：<xxx 字>
开头：<第一段>

### 抖音/视频号口播版
时长预估：<x 分钟>
开头 3 秒：<钩子>
正文骨架：
  1. ...
  2. ...
  3. ...
结尾：<引导>

### 微博版
<140 字内>

【注意】
- 小红书的 emoji 习惯在公众号里要减掉
- 口播稿要念一遍，读着拗口的地方改掉
- 各平台都要过一遍 xhs-compliance-check 的对应规则
```

## 一稿多投的实际操作

**顺序很重要**：

```
1. 先写长版（公众号/知乎）  ← 内容最全
2. 再压成小红书             ← 提炼钩子和密度
3. 最后改口播稿             ← 拆出最核心的 3 个点
```

反过来做（先写小红书再扩写）会显得空洞，因为小红书本来就薄。

## 各平台的合规差异

| 平台 | 特别注意 |
|---|---|
| 小红书 | 最严：站外导流、极限词、导流话术全禁 |
| 公众号 | 相对宽松，但广告法极限词仍禁用 |
| 抖音 | 口播里提到价格、疗效、对比同行要格外小心 |
| 知乎 | 允许专业讨论，但虚构数据会被扒 |
| 微博 | 言论尺度大，但诽谤和造谣会追责 |

**小红书的稿子搬到别的平台通常安全，反过来不行。** 所以从小红书往下游分发风险最低。

## 边界

- **不是复制粘贴**。每个平台都要真正重写，否则读者一眼看出是搬运。
- **不做平台专属合规承诺**。各平台规则变化快，这里给的是通用原则。
- **口播稿必须念一遍**。写出来顺不代表念出来顺。
- 分发后各平台的数据是独立的，别用一个平台的成功推断另一个。

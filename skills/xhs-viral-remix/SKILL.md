# 爆款拆解与原创仿写

目标不是「复制一篇」，是**搞懂它为什么有效，然后用自己的素材重建一遍**。

## 一、拆解：五层模型

拿到爆款，逐层拆。不要跳步。

### 第 1 层｜钩子（决定停留）

标题和首图 / 首句在争同一个东西：**读者是否停下**。

拆什么：
- 钩子类型（情绪落差 / 否定预期 / 数字成果 / 身份痛点 / 悬念提问）
- 钩子指向的对象是否具体
- 有没有"与我有关"的信号（人群词、场景词）

### 第 2 层｜结构（决定读完）

常见三种：

| 结构 | 节奏 | 适用 |
|---|---|---|
| **问题—拆解—方案** | 先扎痛点，再给路径 | 教程、避坑 |
| **结论—证据—延伸** | 先抛结论，再证明 | 测评、观点 |
| **场景—冲突—反转** | 讲故事 | 经历、复盘 |

记录：总共几句话、转折点在第几句、有没有小标题或分点。

### 第 3 层｜信息密度（决定收藏）

数一下：**具体信息**（数字、品牌、价格、步骤、参数）有几处？
这是收藏率的核心。情绪负责点赞，信息负责收藏。

### 第 4 层｜互动设计（决定评论）

- 有没有留问句？
- 是否故意留了一个"可争论点"？
- 结尾是引导收藏、引导评论，还是引导私信（⚠️ 后者在小红书是红线）？

### 第 5 层｜视觉（决定首图点击）

首图的文字量、对比度、主体位置、有没有人物脸。这一层只看图，不评论内容。

## 二、复刻：换骨不换皮

拆完之后，按这个顺序重建：

1. **保留骨架**：第 1、2 层可以用同一个结构
2. **换素材**：把所有具体信息换成用户自己的真实素材
3. **换语态**：用自己的说话习惯重写每一句，不要保留原文句式
4. **换视觉**：首图重新设计，不要用原图
5. **加差异**：至少加一个原文没有的观点、数据或反例

**判断标准**：把两篇放在一起，除了结构相似，**没有任何一句话是雷同的**。

## 三、洗稿红线

这三条，任何一条踩了就是洗稿，不是借鉴：

| 红线 | 说明 |
|---|---|
| ❌ **连续 15 字以上雷同** | 平台查重会命中，用户也会认出 |
| ❌ **只换名词不换句式** | 「我用 A 方法瘦了 X 斤」→「我用 B 方法瘦了 Y 斤」是典型洗稿 |
| ❌ **照抄结论和数据** | 别人的数据不是你的数据，抄了等于造谣 |

**安全的做法**：
- 参考结构和选题角度 ✅
- 用自己的真实经历和数据 ✅
- 明确标注"参考了某篇的思路" ✅（小红书不禁止，反而加分）
- 标注来源并给出自己的新结论 ✅

## 四、选题迁移

爆款的选题往往能迁移到相邻领域。迁移公式：

```
原爆款：<人群 A> + <场景 B> + <痛点 C> + <钩子 D>
新选题：<人群 A'> + <场景 B> + <痛点 C> + <钩子 D>
```

只换人群，最容易成功。因为场景和痛点被验证过有效。

例：
- 原：干皮 + 冬天 + 卡粉 + 数字结果
- 新：油皮 + 夏天 + 脱妆 + 数字结果

## 五、产出格式

```
【拆解】
钩子：<类型> —— <为什么有效>
结构：<哪种> —— <转折在第几句>
信息密度：<几处具体信息> —— <收藏潜力>
互动设计：<有什么> —— <是否踩红线>
视觉：<首图特征>

【复刻建议】
保留：<骨架、选题角度>
必须换：<素材、句式、视觉>
可加差异：<建议的具体点>

【成稿】
标题：<20 字内>
正文：<按结构写>

【风险提示】
<是否接近洗稿、是否有违规词、建议再跑 xhs-compliance-check>
```

## 边界

- **拿不到原文就不要硬猜**。用户只给了一个标题时，只能拆钩子那一层，明确告诉用户"缺正文，后四层无法拆"。
- **不复刻违规内容**。原文如果有极限词、导流话术，仿写时必须去掉，不能因为"原文也这么写"就保留。
- **不保证爆**。结构和钩子提高概率，不决定结果。别向用户承诺数据。

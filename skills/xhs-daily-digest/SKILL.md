# 每日简报与定时任务

## 立场先说清

**这个工具不做自动采集。**

理由：自动刷小红书要登录、要浏览器、有封号风险，而且抓来的"热点"往往跟你的账号没关系。真正有价值的每日输入，应该来自**你自己积累的知识库**。

所以 `digest.py` 只做一件事：把你已有的选题、爆款库、复盘状态，整理成今天该做什么。

## 生成简报

```bash
python3 ~/.claude/skills/xhs-daily-digest/scripts/digest.py
```

输出长这样：

```
# 今日选题简报 · 2026-11-20

## 待写选题（3 个）
- 被 AI 惊到后我改掉的三个习惯（2 天前）
- 租房改造 300 块预算（15 天前）⏰ 已久

## 爆款库（8 条，最近 3 条）
- 某工具测评爆款拆解
- ...

## 📊 该复盘了
上次复盘是 35 天前。

## 今天做一件事
把「被 AI 惊到后我改掉的三个习惯」写出来。
```

写进文件：

```bash
python3 ~/.claude/skills/xhs-daily-digest/scripts/digest.py --out ~/xhs/output/daily.md
```

## 定时执行

### 用 crontab（Muse 上最直接）

```bash
python3 ~/.claude/skills/xhs-daily-digest/scripts/digest.py --cron
```

它会打印现成的 crontab 行，复制到 `crontab -e` 里即可。默认每天早 8 点。

要点：
- **用绝对路径**，cron 的环境变量很少
- 想让它推送给你，末尾接一条通知命令（见下）

### 接通知

Muse 上如果需要每天早上收到提醒，可以接：

```bash
# 写文件后打印到日志，Muse 的会话里能看到
0 8 * * * python3 .../digest.py --out ~/xhs/output/daily.md && cat ~/xhs/output/daily.md

# 或者接你自己的通知渠道（webhook 等）
0 8 * * * python3 .../digest.py --out ~/xhs/output/daily.md && curl -X POST <webhook> -d @~/xhs/output/daily.md
```

## 能定时做什么，不能做什么

| 可以定时 ✅ | 不要定时 ❌ |
|---|---|
| 生成选题简报 | 自动发布笔记 |
| 提醒该复盘了 | 自动回复评论 |
| 检查草稿箱里待发的稿 | 批量点赞/收藏 |
| 生成卡片的 HTML 预览 | 自动登录 |
| 备份知识库 | 自动刷首页采集 |

**右列这些都要登录态，定时无人值守地跑，是封号最快的路径。**

## 建议的定时组合

```
早 8:00   生成选题简报，推送给我
晚 21:00  检查 ~/xhs/drafts/ 里有没有写了一半的稿，提醒我
每周一    提醒做上周复盘
每月 1 日 提醒做月度复盘
```

这些全是**只读本地文件**的操作，零风险。

## 边界

- 简报质量取决于知识库质量。知识库空，简报就是一堆"空。用 xxx 生成一批。"
- 不替你做决定。它告诉你"今天有 3 个待写选题"，写哪个由你定。
- cron 在容器/云环境里可能被限制，装完先手动跑一次确认，再上 crontab。
- 自动采集相关的能力**故意没做**，要的话必须人工介入。

# 小红书文案合规自检

发布前的最后一道检查。**纯本地运行，文案不出本机。**

## 怎么跑

```bash
# 直接传文案
python3 scripts/check.py "你的文案内容"

# 从文件读（长文案推荐）
python3 scripts/check.py --file draft.txt

# 从管道读
echo "文案" | python3 scripts/check.py -

# 机器可读输出
python3 scripts/check.py --file draft.txt --json
```

脚本路径相对于本 skill 目录。不需要装任何依赖，Python 3.8+ 即可。

## 词库覆盖

| 分类 | 等级 | 典型命中 |
|---|---|---|
| 站外导流 | 🔴 高危 | 微信、加v、公众号、淘宝、私信领、二维码 |
| 极限用语 | 🔴 高危 | 第一、最好、国家级、顶级、100%、绝对、独家 |
| 医疗与功效 | 🔴 高危 | 治疗、消炎、减肥、排毒、祛疤、降血压 |
| 化妆品夸大 | 🟡 中危 | 特效、速白、溶脂、瘦脸、去除皱纹 |
| 权威性背书 | 🟡 中危 | 质量免检、特供、中国驰名商标 |
| 虚假紧迫 | 🟡 中危 | 秒杀、抢爆、万人疯抢、错过就没机会 |
| 诱导互动 | 🔵 低危 | 一键三连、恭喜获奖、全民免单 |
| 迷信用语 | 🔵 低危 | 招财进宝、逢凶化吉、旺财、时来运转 |
| 联系方式/外链 | 🔴 高危 | 手机号、http 链接（自动正则识别） |

词库在 `scripts/words.json`，可直接编辑增删。用户反复被某个词卡住，就把它加进去。

## 怎么用结果

1. **先看高危**。有高危词就别发了，先改。
2. **替换建议不是唯一解**。`words.json` 里的 `replacements` 是通用平替，真正好的改法是结合语境重写那一句。机械替换容易读起来别扭。
3. **误报是正常的**。比如"第一次用"里的"第一"、"最大值"里的"最大"。判断标准是**这个词有没有在给产品背书或做绝对化承诺**，没有就放过。
4. **改完再跑一遍**，确认清零。

## 边界（必须跟用户说清）

- **词库会过时**。平台规则一直在变，本地词库只能兜底，替代不了发布前人工通读。
- **通过检测 ≠ 一定过审**。图片违规、资质问题、内容真实性、账号权重，这些都不在词库范围内。
- **词库不保证完备**。它覆盖的是高频风险词，不是穷举。
- 不联网是特性不是缺陷 —— 意味着文案不会发给任何第三方，但也意味着词库靠手动更新。

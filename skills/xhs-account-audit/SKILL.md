# 账号体检与复盘

用**用户自己粘贴的数据**做分析。不自动抓取的原因很简单：抓取要登录，登录有封号风险，而这些数据在创作者中心本来就能看到，复制成本很低。

## 怎么用

### 1. 让用户准备数据

CSV 最省事，表头固定：

```csv
date,title,likes,collects,comments,views
2026-11-01,我的第一篇笔记,120,45,8,3000
2026-11-05,被 AI 惊到了,850,320,96,12000
```

JSON 也行：

```json
{"notes": [{"date": "2026-11-01", "title": "...", "likes": 120,
           "collects": 45, "comments": 8, "views": 3000}]}
```

`views`（浏览量）可留空，脚本会跳过相关指标。

不确定格式时让用户跑：

```bash
python3 ~/.claude/skills/xhs-account-audit/scripts/audit.py --sample
```

### 2. 跑分析

```bash
python3 ~/.claude/skills/xhs-account-audit/scripts/audit.py --file ~/xhs/notes.csv
```

### 3. 读结果，别只贴输出

脚本给的是数字，**你要翻译成行动**。三个核心信号：

| 信号 | 含义 | 该做什么 |
|---|---|---|
| **收藏率高（≥35%）** | 读者认为值得回看，信息密度够 | 做成系列，复制这个结构 |
| **收藏率低（<15%）** | 看完了但没存，内容太泛 | 下一篇每段塞一个具体信息 |
| **评论率低（<3%）** | 结尾没钩子 | 加具体问题，别用"评论区告诉我" |
| **数据断层（最高 > 中位数 5 倍）** | 账号标签不稳，算法在试探 | **接下来 5-7 篇统一风格，别换赛道** |

数据断层是最容易被忽视的关键期。很多人这时候会兴奋地换题材追流量，结果账号标签废掉。

## 复盘模板

分析完，把结论存进知识库：

```bash
echo "## 数据
- 篇数: 12
- 中位互动: 18
- 收藏率: 26%
- 评论率: 7%

## 结论
- 数据断层严重（68x），账号标签未稳
- 高表现集中在 AI 工具类

## 下一步
- 连续 5-7 篇锁定 AI 工具方向
- 每篇补一个具体数字
- 结尾加二选一提问" | python3 ~/.claude/skills/xhs-knowledge-base/scripts/kb.py \
  add review --title "2026-11 月度复盘" --tags "复盘,标签期"
```

## 输出格式

```
【数据概览】
12 篇 · 中位互动 18 · 收藏率 26% · 评论率 7%

【诊断】
⚡ 数据断层（最高是中位数的 68 倍）
  → 账号标签还没稳，平台在试探推流。
  → 动作：接下来 5-7 篇统一风格和主题，别换赛道。

【表现最好的】
· 被 AI 惊到了（互动 1266）
  → 这是已验证的骨架，用 xhs-viral-remix 拆它。

【建议下一步】
1. ...
2. ...

存进知识库吗？
```

## 边界

- **数据是你给的，不是抓的**。数据错了结论就错了，让用户核对再分析。
- **不预测流量**。趋势判断是概率，不是承诺。
- **样本少于 5 篇时不下趋势结论**，只说"样本不够"。
- 浏览量缺失时，所有跟浏览量相关的指标（CTR）都不算，明确告诉用户。

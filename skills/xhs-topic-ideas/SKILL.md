# 选题灵感生成

选题不是想出来的，是**从已有素材里拆出来的**。本 skill 的输入永远来自三处：账号人设、爆款拆解库、用户当下提供的素材。凭空编选题没有意义。

## 一、先读两份东西

动手前必须先看：

```bash
python3 ~/.claude/skills/xhs-knowledge-base/scripts/kb.py persona
python3 ~/.claude/skills/xhs-knowledge-base/scripts/kb.py list pattern
```

- **persona.md** 决定选题的边界和语气
- **patterns/** 里有已验证的爆款骨架，优先复用

如果 persona 还是空模板，先停下来问用户，不要瞎猜。

## 二、四个选题来源

| 来源 | 怎么用 | 产出质量 |
|---|---|---|
| **爆款迁移** | 拿 patterns 里的骨架，换人群或场景 | 最稳 |
| **痛点反推** | 从 persona 里"他们最烦什么"反推 | 稳定 |
| **经历挖掘** | 从 persona 里"三个真实细节"深挖 | 独特性最高 |
| **热点结合** | 用户提供热点素材，找与账号的连接点 | 时效强但风险高 |

**优先级：经历挖掘 > 爆款迁移 > 痛点反推 > 热点结合。**
自己的真实经历无法被抄，热点最容易撞车。

## 三、五维评分

每个选题打五维分，每维 1-5 分，总分 25：

| 维度 | 问什么 | 低分信号 |
|---|---|---|
| **相关性** | 和账号定位有多贴？ | 需要绕两个弯才说得通 |
| **独特性** | 只有我能写吗？ | 谁都能写 |
| **可验证** | 我有真实素材/数据支撑吗？ | 只能泛泛而谈 |
| **互动潜力** | 能引发评论吗？ | 读者看完无话可说 |
| **风险** | 会踩违规或争议吗？（**反向计分**：风险越高分越低） | 涉及医疗、价格、对比同行 |

**总分 ≥ 20**：优先做
**15-19**：可做，需要补素材
**< 15**：放弃

## 四、产出格式

```
【选题池】基于 <人设 + N 条爆款库>

1. <选题标题（20 字内）>
   角度：<一句话说清从哪切入>
   来源：<爆款迁移 / 痛点反推 / 经历挖掘 / 热点结合>
   评分：相关 4 · 独特 5 · 可验 4 · 互动 4 · 风险 2 → 19/25
   需要的素材：<用户还缺什么>
   风险：<可能踩的线>

2. ...

【推荐】
第 N 个优先做，因为 <理由>。

【要不要存】
要我把这 N 个选题写进知识库吗？（会存到 ~/xhs/topics/）
```

## 五、存入知识库

用户同意后：

```bash
echo "<选题详情>" | python3 ~/.claude/skills/xhs-knowledge-base/scripts/kb.py \
  add topic --title "<选题标题>" --tags "待写,评分19"
```

后续写完、发完、复盘，改 tags 里的状态（`待写` → `已写` → `已发` → `已复盘`）。

## 边界

- **不编造热点**。拿不到实时数据就说拿不到，不要虚构"最近很火的 XXX"。
- **不保证爆**。评分是概率判断，不是预测。
- **选题必须来自 persona 或用户素材**。凭空生成等于让用户去写别人的内容。
- 选题里的标题方案要再过一遍 `xhs-title-optimizer` 和 `xhs-compliance-check`。
